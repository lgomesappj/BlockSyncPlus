# BlockSyncPlus

BlockSyncPlus enables real-time, fault-tolerant block-level synchronization and replication for high-availability data services management.

The key benefits of using BlockSyncPlus include:

- BlockSyncPlus enables real-time, fault-tolerant block-level
- synchronization and replication for high-availability
- data services management

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/BlockSyncPlus.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
